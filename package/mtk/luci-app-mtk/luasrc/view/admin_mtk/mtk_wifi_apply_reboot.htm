重启设备

由于驱动不支持动态添加或删除接口， 在添加或删除接口期间更改的设置尚未应用！

更改的设置只有在设备重启后才会应用。 请点击重启按钮。

提示：
请在重启前添加或删除所有需要的接口，以免需要再次重启设备。
请按照以下说明添加或删除接口：
1. 进入 无线概览 页面。
2. 点击添加按钮添加新接口，或点击删除按钮删除现有接口。
3. 如果正在添加新接口，请在填写完SSID等所有必填字段后点击保存按钮。
4. 完成接口的添加/删除后，请点击任意页面上的重载按钮或 保存并应用按钮，系统将重定向到此页面以执行设备重启。

请稍候，设备重启正在进行中。

设备尚未恢复在线！
